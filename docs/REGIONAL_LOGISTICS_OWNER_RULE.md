# Regional Logistics Owner Rule

DO NOT CREATE PARALLEL SYSTEMS. EXTEND THE EXISTING OWNER.

- Economy/reserves/contracts/route risk → `KeloRegionalEconomy`.
- Pure risk/economic-distance formulas → `KeloRegionalEconomyMath`.
- Physical item/container movement → `KeloContainers`.
- Cart lifecycle/possession → `KeloCaravans`.
- Faction/clan identity/permissions → `KeloFactions`.
- Player trade/stalls/market escrow → `KeloCommerceAuthority`.
- Combat resolution → existing combat owners.
- NPC behavior → existing NPC owner.
