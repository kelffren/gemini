# Regional Logistics V1 — Scope Boundary

Implemented now: regional resources/settlements/reserves/production/prices/contracts/risk graph/world-event modifiers, physical carts with shared inventory, faction/clan identity and permissions, offline persistence, authority boundaries, debug/testing.

Prepared but intentionally not built: territorial war, full diplomacy, espionage, clan banking/warehouse, faction armies, auction house replacement, automated shipping, caravan insurance, taxes, seasons, scouting/sealed/false cargo gameplay.

Those future features must extend the owners documented in `docs/systems/REGIONAL_ECONOMY_LOGISTICS_SYSTEM.md`.
